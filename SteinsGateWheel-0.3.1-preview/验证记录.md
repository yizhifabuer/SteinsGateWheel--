# 0.3.1 验证记录

日期：2026-11-08。最终构建已通过 **72 项检查**，完整输出见发布包中的 `desktop-isolation-results.txt`。

## 本次测试边界

没有运行正式补丁、安装器或游戏，没有使用 computer-use，没有调用 SendInput 或修改鼠标指针的接口，没有为本机设置自启。真实鼠标钩子仅注册在从未切换显示的独立测试桌面。

输入测试使用 FakeBackend；安装测试使用内存注册表、模拟进程宿主及工作目录中的专用夹具。监护测试真正创建并终止独立控制台测试进程，但这些进程只读写测试用共享内存和模拟心跳。

另有受监护探针验证真实 Win32 鼠标钩子的正常退出及两类线程卡死。探针先验证自己的桌面名与用户输入桌面不同，再注册钩子；不包含输入注入、鼠标修改和桌面切换接口。每次测试前后都核对用户输入桌面未变。

这不是虚拟机内的真实游戏兼容性测试，也不包含真实鼠标点击输入测试。

## 已验证

- Steam 库解析：转义路径、中文和空格路径、多库、重复库、错误 App ID、路径越界及缺失库。
- 安装器嵌入载荷与编译产物一致，Win32 INPUT 结构大小正确，自启命令正确引用含空格路径。
- 快速五格下滚转换五组完整点击；高精度滚轮累计；保留上滚及非游戏输入。
- 队列取消、切换目标、过期和上限；取消使已经取出的旧请求失效。
- 焦点失效及左键按住时不发送；按下后取消或异常时仍尝试松开。
- 发送失败后停止执行，无限重试被禁止；模拟重入不会死锁；锁被占用时回调入口立即返回。
- 模拟安装、卸载、保留无关文件与启动值、启动失败回滚、升级回滚、登记自启失败回滚，以及旧程序无法停止时不继续写安装文件。
- 鼠标处理线程卡死：模拟测试子进程 1158ms 后退出。
- 点击线程卡死：模拟测试子进程 1153ms 后退出。
- 卡死且工具持有左键：模拟测试子进程 1108ms 后退出，模拟松开回调执行一次。
- 初始化无响应：模拟测试子进程 5065ms 后退出。
- 每种超时只调用一次致命停止回调；正常停止有时间上限。
- 监护界面失去响应时终止输入子进程；输入子进程失去父心跳时自行退出。
- TickCount 回绕、撤回许可及停止请求均有覆盖。
- 构建产物不直接导入隐藏、移动、替换、锁定指针、阻止系统输入或切换桌面的原生接口。
- 生成的 INPUT 仅为左键按下 / 松开，坐标及滚轮字段均为零，带循环防护标记。
- 模拟 Windows 拒绝终止，以及没有收到退出完成信号：均明确记录未确认，不能当作已关闭；句柄释放也不能改变这个结论。

- 非显示桌面真实钩子的鼠标处理线程卡住：1084ms 后确认退出。
- 非显示桌面真实钩子的点击线程卡住：1085ms 后确认退出。
- 每一组真实钩子探针测试前后，用户输入桌面均未改变。

## 尚需用户验证

2026-11-08，用户反馈 0.3.1 已测试可用、未发现问题。随后只读检查确认本机安装文件存在，当前用户 Run 自启值正确指向安装目录的后台程序。

该反馈没有细分两部游戏与各模式覆盖。重新登录后自启、完整卸载流程及更广泛真实环境覆盖仍需补充，不把已登记启动项等同于已完成重新登录实测。

不能据模拟测试承诺在 Windows 内核异常或权限拒绝时仍能强制终止进程，也不能宣称之前鼠标不可见的精确根因已经被定位。

## 之前的鼠标显示事件

旧测试程序出现未响应，自动化滚轮调用超时。用户报告指针不可见时，GetCursorInfo 返回 flags=1（显示中）。重置自动化会话未恢复；重新加载当前系统指针、解除限位并移回主屏后，用户确认显示与操作恢复。期间没有修改游戏和存档。

随后用户发现 Steam 再次打开仍未响应，补丁托盘图标仍在。更完整的检查发现：旧 Steam 网页进程及旧补丁各留有一个线程，虽然已有退出码，进程句柄等待仍返回超时。这说明先前仅据退出码、任务栏按钮消失判断“关闭完成”是不充分的。用户正常重启后确认一切恢复。

这些信息不能唯一确定鼠标不可见的精确根因。0.3.1 修正退出确认方式，增加禁止指针操作的构建检查，以及非显示桌面的真实钩子生命周期测试；不能将这些改动等同于已证实消除所有指针显示故障。
