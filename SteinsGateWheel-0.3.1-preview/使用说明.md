# 命运石之门滚轮翻页 · 0.3.1 手动测试版

一个游戏功能：**向下滚轮等同左键单击**，快速滚动连续点击，保留原左键。支持 Steam 版 STEINS;GATE 原版（412830）和 STEINS;GATE 0（825630）。

## 安装一次，以后自动生效

1. 运行本包中的 `SteinsGateWheelSetup.exe`。
2. 点击 **安装并启用**。
3. 以后直接从 Steam 启动任意一部游戏即可。

工具自动寻找 Steam 游戏库，不用选择路径，不用设置游戏启动参数。首次安装立即运行，以后在当前 Windows 用户登录时自动后台启动。没有参数面板、F8 快捷键、自动快进或翻译功能。

本版本通过 72 项检查，包括模拟输入、独立测试子进程，以及非显示 Windows 桌面上的真实鼠标钩子生命周期测试。用户已反馈安装使用正常，并已只读确认安装文件及当前用户登录自启项存在；**实际重新登录后的自启，以及两部游戏各模式的完整覆盖尚未单独确认**。测试边界详见 `验证记录.md`。

## 操作行为

- 每个标准下滚刻度产生一次左键按下与松开；高精度滚轮不足一格的位移会累积。
- 按下 35ms，松开后间隔 45ms。游戏文字未显示完时，一次点击可能先补全文字；过场、加载等输入锁定仍由游戏处理。
- 左键、右键及向上滚轮保留。上滚、手动点击、切出游戏、鼠标离开游戏窗口会取消未执行点击。
- 最多排队 64 次；队列超过 6 秒未继续滚动会过期，防止残留输入持续推进。
- 菜单、手机和存读档界面中的下滚也等同点击鼠标所在位置。工具不读取剧情状态。
- 仅在核实的目标游戏处于前台时注册鼠标钩子，离开目标游戏即解除。其他应用中的滚轮和鼠标移动不被替换。

## 未响应时自动停止

后台包含两个职责分开的进程：监护程序和输入程序，名称均为 `SteinsGateWheel.exe`。

监护每 50ms 检查鼠标处理线程和点击线程的心跳；任何一个超过 1 秒无心跳，便请求终止输入程序、记录错误并结束本次运行。监护界面线程超过 1 秒无心跳，也会触发停止。初始化阶段允许最多 5 秒，但此时必须有监护许可才能启用输入。

模拟卡死和非显示桌面的真实钩子卡死测试中，已初始化的测试子进程约 1.1 秒后退出；未初始化的子进程约 5.1 秒后退出。0.3.1 使用进程退出完成信号进行确认，不再凭退出码或 `.HasExited` 判断清理成功；确认失败会明确记录“未确认退出”或“拒绝终止”。这不是“零延迟”保证，Windows 调度、权限或内核故障仍可能阻止及时终止。

异常停止后**本次不会自动重新启动**。输入进程若失去监护心跳，也会主动结束。若故障发生在工具按下左键后，会尝试通过另一个受超时限制的临时进程松开工具自己的点击；不隐藏、替换、移动或锁定鼠标指针。

最后一条错误保存在 `%LOCALAPPDATA%\SteinsGateWheel\last-error.txt`，不记录游戏文本、存档或个人路径。

## 停止与卸载

- 临时停止：右键托盘图标选择“退出本次运行”，或双击包内 `停止补丁.cmd`。下次登录 Windows 仍会自动启动。
- 完全移除：Windows“设置 → 应用”中卸载 **命运石之门滚轮翻页（原版 / 0）**，或从托盘菜单选择“卸载”。

工具按当前用户安装在 `%LOCALAPPDATA%\SteinsGateWheel`，不需要管理员权限。游戏也应正常以普通权限启动。

安装一次后，登录 Windows 自动运行；不是每次打开游戏才启动工具。后台正常运行时一直可用。手动退出或异常停止后，若本次还要继续使用，可运行上述安装目录内的 `SteinsGateWheel.exe`，不用重新安装；下次登录也会自动运行。只支持原版和 0，不是所有游戏通用映射。

## 文件与存档

不修改游戏文件，不注入游戏进程，不读写存档，也不更改系统鼠标图像或鼠标主题。模拟点击会触发游戏的正常行为，包括游戏自己执行的保存，因此不要在存读档菜单中连续下滚。

## 开发和发布

运行 `build.ps1` 生成单文件安装包；运行 `tests/prepare.ps1` 执行隔离模拟检查。测试使用模拟输入后端、内存注册表和工作目录内的临时文件；卡死测试只启动控制台测试子进程，不注册真实鼠标钩子，不发送输入，不使用 computer-use。

通过 `tests/prepare.ps1 -DesktopIsolation` 可额外执行真实钩子生命周期检查：只在新建、从不切换显示的 Windows 桌面启动探针，探针确认自身不在用户输入桌面后才注册钩子。该探针不包含 SendInput、鼠标指针修改和桌面切换接口；没有隔离权限时直接失败，不回退到日常桌面。

上述隔离**不是虚拟机中运行真实游戏**，也没有向用户桌面注入输入。真实点击输入、两部游戏兼容性和登录自启仍需手动确认。构建产物有自动检查，禁止直接导入隐藏、移动、替换、锁定指针或切换桌面的原生接口；这不等同于保证 Windows、游戏或其他软件永远不会让指针不可见。

GitHub 可上传源码，并在 Releases 附件提供 `SteinsGateWheelSetup.exe` 或本测试压缩包。当前是预览测试版，手动验证通过前不要标为稳定版。
