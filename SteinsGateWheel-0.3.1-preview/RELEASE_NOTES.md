# SteinsGateWheel 0.3.1 Preview

为 Steam 版 STEINS;GATE 原版和 STEINS;GATE 0 增加下滚等同左键的操作，支持连续滚动，保留原左键。

下载 `SteinsGateWheel-0.3.1-preview.zip`，解压并运行 `SteinsGateWheelSetup.exe`，点击“安装并启用”。安装一次后，登录 Windows 自动后台运行，以后正常从 Steam 打开游戏即可。

- 自动识别游戏安装路径，仅对这两个游戏生效。
- 不修改游戏文件或存档。
- 独立监护输入进程；故障时请求停止，本次不自动重启。
- 可通过托盘退出，或从 Windows 应用设置卸载。

72 项自动检查通过，用户已反馈实际安装使用正常。跨登录自启和更广泛兼容性仍需补充验证，因此本次为 Preview。

已安装的启动项若被手动禁用，或后台程序被手动退出，本次不会在打开游戏时再次拉起。下次登录 Windows 会按启动项设置运行。
