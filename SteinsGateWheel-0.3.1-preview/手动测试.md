# 0.3.1 手动测试

请只使用本次 Release-0.3.1 包，勿运行旧 `tests/runtime` 目录中的程序或 0.3.0 包。

## 开始前

测试前确认 Steam 与鼠标工作正常，旧版补丁没有运行；不要同时运行多个版本。正常安装本包不要求专门重启电脑。

本包不会由助手自动执行。游戏文件和存档不需要改动；优先使用新游戏开头或可以放弃的进度测试。

## 安装和原版

1. 双击 `SteinsGateWheelSetup.exe`，点击“安装并启用”。
2. 在桌面或浏览器滚动，确认鼠标移动、点击、滚轮和指针显示正常。
3. 正常从 Steam 启动 STEINS;GATE 原版，进入剧情，把鼠标放在非按钮的文本区域。
4. 分别试下滚一格、连续下滚几格、原来的左键单击。
5. 向上滚动，确认历史记录操作保留；返回剧情后继续测试。
6. 快速下滚后立即切出游戏，确认桌面没有后续点击；返回后确认没有遗留队列。
7. 关闭游戏，确认桌面的鼠标和滚轮仍正常。

## 0 与自启

按相同步骤测试 STEINS;GATE 0。随后保存工作并重新登录或重启 Windows，直接打开游戏，确认不用手动运行工具也能下滚。

## 停止和卸载

双击 `停止补丁.cmd`，确认滚轮恢复游戏原行为。停止后要再次试用，可运行安装目录中的 `SteinsGateWheel.exe`；正常日常使用不需要这一步。

再从 Windows“设置 → 应用”卸载，确认下次登录不再生效。卸载后若目录里没有其他文件，工具会移除自己的安装目录。

## 出现问题

如鼠标显示异常、桌面点击异常或游戏漏接输入，先停止测试，用 `停止补丁.cmd` 关闭新版，保留 `last-error.txt` 内容并反馈。未响应保护已做模拟验证，但不应在日常桌面故意制造真实鼠标钩子死锁。

反馈请包含：原版或 0、是否全屏、异常出现时的操作、错误记录内容。无需提供存档。
